## Recent GitHub Blog and Changelog highlights

- Copilot code review can now approve pull requests, and got an improved review experience — Copilot's PR reviews are becoming a full step in the merge workflow (github.blog/changelog).
- The repository pull requests page has a refreshed public preview with better filtering and a more compact list view (github.blog/changelog).
- GitHub Actions added workflow execution protections (now generally available), letting maintainers restrict who can trigger workflow runs (github.blog/changelog).
- GitHub now blocks pull requests containing exposed secrets from merging, adding another layer of push protection (github.blog/changelog).
- The GitHub CLI (`gh`) supports attaching media like images and video directly to issues, pull requests, and comments (github.blog/changelog).
- Copilot app tutorials cover running multiple agents in parallel and using Copilot to triage Dependabot pull requests, showing practical multi-agent workflows (github.blog).
- The community-maintained [awesome-copilot](https://github.com/github/awesome-copilot) repository curates ready-made Copilot agentic workflow templates — including issue triage, stale-repo reports, and release compliance checks — useful examples for automating repository maintenance.
